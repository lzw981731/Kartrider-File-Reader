# Rho檔案
## 概述
### Rho檔案是什麼？
Rho檔案儲存了跑跑卡丁車遊戲資源。它類似於zip、rar、7z這類我們耳熟能詳的檔案格式，
一個Rho檔案就能儲存多個遊戲資源檔案，也可儲存資料夾，只是Rho檔案專門用來儲存跑跑卡丁車的遊戲資源。
### 我該如何開啟它？
理論上應該只有跑跑卡丁車本人才知道Rho檔案應該如何開啟。

但為何是理論上呢？因為事實上，早期網路上就有Rho檔案的拆檔軟體。

這裡只舉我用過的臉蛋看看為例，這套軟體可以讀取Rho的遊戲資源，如ogg音樂檔、還有各種圖片紋理檔案。

那這類軟體是如何知道Rho檔案的架構？首先先設想一個問題，除了跑跑卡丁車開發者外，有誰還會知道Rho的檔案架構？

答案就是跑跑卡丁車客戶端，但這時候又會有個疑問，我要如何知道跑跑卡丁車客戶端是如何開啟Rho檔案的？

在回答這問題之前，必須先了解電腦程式是如何運作的。

在工程師熬夜爆肝終於把程式碼肝完後，在歷經各種熬夜加班Debug後，就可以把程式碼編譯了。

編譯器會把這些程式碼變成機器碼，當然這過程十分複雜，但這不是這裡談論的重點，而這機器碼就是電腦實際上看得懂的東西。

而當你開啟某支程式時，作業系統會把程式內的機器碼(text section)放到記憶體中,並且會開始執行這些機器碼，程式沒意外的話就會照著開發者所設計的開始運作。
在了解了電腦程式是如何運作的以後，只要把機器碼讀過一輪就能知道這套程式大致上是如何運作的，這種操作稱之「逆向工程」。

當然，能直接用機器碼解讀程式運作流程的人大概不多，ARM架構這類每道指令都是32位元(4 Bytes)以及RISC家族的可能都勉強還能做到，但X86這種指令長度最小可以小到1 byte，最長可以到15 bytes的架構，讀機器碼這種事還是交給電腦吧......

畢竟機器碼也是由組合語言經Assembler轉成機器碼的，這時候就要把機器碼再轉回組合語言來表示呈現這些機器碼所做的操作，而只要能正確找到哪個群指令是在將Rho檔案解密、解碼，便可知道Rho檔案的架構。

在知道這類程式是如何知道Rho檔案架構的原理後，這時便可以知道要如何開啟Rho檔案了，那就是逆向工程後，直接設計一支程式，然後讀取Rho檔，就大功告成了！
~~就　是　這　麼　簡　單　！~~

即使只要讀懂跑跑卡丁車程式的運作流程，找到Rho檔案解密、解碼用指令後，就可以知道Rho檔案架構，但是逆向工程是十分消耗時間的，所以也不見得都可以很快找到Rho讀取的函式。

而這個函式庫便是利用對某版跑跑卡丁車逆向工程來得知Rho的檔案架構，你便能很輕易的使用此函式庫開啟Rho檔案。

## 使用方法
```csharp
//開啟Rho檔案
RhoArchive rhoArchive = new RhoArchive();
rhoArchive.Open("(Your Rho file path.)");

```
